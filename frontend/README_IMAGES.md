# CivicAI field imagery

The Overview uses the user-provided civic-service photograph as the primary local image. Additional field cards use remote image sources for water/sewer maintenance, waste collection, road repair, and street-light maintenance. If an external image cannot load, the card automatically falls back to the built-in CivicAI illustration.

External image sources used in the UI:
- Water/sewer maintenance: Jutarnji List image source
- Waste collection: Stari Grad Belgrade image source
- Road repair: Antena 3 CNN image source
- Street lighting: Gobierno de Jalisco image source

For a production deployment, download/host appropriately licensed copies locally and replace the remote URLs.
