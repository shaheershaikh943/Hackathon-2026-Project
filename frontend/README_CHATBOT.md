# CivicAI Chatbot — v12

A global CivicAI help assistant is available from every page through the floating ✦ button.

## Features
- Chat-style conversation history
- Quick prompts for water, waste, roads and street lighting
- Situation assessment
- Urgency level
- Recommended civic department
- Quick-response guidance
- Typing indicator and animated UI
- Clear chat action
- Keyboard Enter/Escape support
- Responsive mobile layout
- Dark-mode support

The assistant currently uses the project's local `AISuggestion` rule engine, so it works without a separate AI API key. It is advisory decision support and should not be treated as a verified on-site assessment.
